# MiDinero PWA — versión personalizada

Aplicación web de finanzas personales hecha solo con HTML, CSS y JavaScript, compatible con GitHub Pages y con instalación desde Safari en iPhone.

## Presupuesto inicial
Sueldo 1.409 €/mes (12 pagas), cobro entre días 28 y 30, vivienda 400 €, gasolina 150 €, seguro 64 €, cuota 5,98 € hasta abril de 2027, gastos personales 100 €, ocio 200 €, ahorro moto 275 €, colchón 150 € y margen previsto 64,02 €.
Moto: 3.000 € antes del 11 de septiembre de 2027. Colchón fase inicial: 1.000 €.

## Uso
Abre la página publicada por GitHub Pages y en Safari toca Compartir > Añadir a pantalla de inicio. Registra la nómina únicamente cuando se reciba realmente; registra compras y ahorros manualmente. Se pueden modificar las cantidades desde Ajustes. Las copias JSON y CSV se descargan al dispositivo.

## Seguridad y privacidad
Solo almacena datos en localStorage del navegador, sin servidor ni conexión bancaria. No subas copias de tus movimientos al repositorio público. Los datos se pueden perder si borras el almacenamiento del navegador: haz copias de seguridad periódicas.

## Versión anterior
El proyecto previo de MiDinero se conserva en /anterior/ con su código intacto. Usa la clave localStorage `midinero_state_v1`; la nueva versión usa `midinero_finanzas_v2`. No se borran ni se migran automáticamente los datos de la versión antigua.
